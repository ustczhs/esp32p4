**已接入固件播放**（`EyePlayer` 直接显示 400×200，无运行时镜像）。

源目录：`/home/zhs/Downloads/一代眼睛动画/一代眼睛动画/*.mp4`（1200×800）。

处理方式：
- 从每帧固定裁左右眼各 **420×420**（比首版 300 多留边距，避免圆边被切）
- 各缩放到 200×200 后水平拼接 → **400×200**
- 帧率 12fps，GIF 无限循环
- **不做镜像**：左右眼均取自源片真实画面

# 使用串口切换眼睛
sudo apt install minicom
sudo minicom -D /dev/ttyACM0 -b 115200
进终端后：
按回车
输入 eyes 再回车
应出现 0-22 列表，再输入数字切换。
退出 minicom：Ctrl+A，再按 X，选 Yes。
